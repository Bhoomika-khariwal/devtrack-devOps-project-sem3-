SCM and Version Control

Learn how developers manage code changes and collaborate safely on software projects.

1. What is SCM?

Source Code Management (SCM) is the process of tracking, organising and managing changes made to source code. It helps developers work together and maintain a history of their changes.

2. What is Version Control?

Version control records different versions of files. It allows developers to see previous changes, compare versions and recover earlier work when needed.

3. What is Git?

Git is a distributed version control system. Each developer can keep a local repository and work on changes independently.

4. Important Git Concepts

  • Repository: Stores project files and history.
  • Working directory: Where you edit files.
  • Staging area: Holds changes selected for the next commit.
  • Commit: A recorded snapshot of changes.
  • Branch: An independent line of development.
  • Remote: A repository hosted elsewhere, such as GitHub.

5. Basic Git Workflow

git status
git add .
git commit -m "Add lesson content"
git push

Check the status, stage your intended changes, commit them and push your commits to a remote branch. For a new branch, configure its upstream when pushing.

6. Clone, Push and Pull

  • git clone copies a remote repository locally.
  • git push uploads local commits to a remote.
  • git pull fetches and integrates remote changes.
