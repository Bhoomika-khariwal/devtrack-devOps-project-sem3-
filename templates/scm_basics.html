SCM and Version Control

Module 02 · Beginner level · About 15 minutes

1. What is Source Code Management (SCM)?

Source Code Management is the process of tracking, organising and managing changes made to source code. It helps developers work together and maintain a history of their changes.

2. What is Version Control?

Version control records changes made to files over time. Developers can compare different versions, view previous changes and recover earlier work when needed.

3. Types of Version Control Systems

Local VCS

Stores file versions on one local computer.

Centralized VCS

Uses a central server to store project history.

Distributed VCS

Each developer can maintain a complete local repository.

4. What is Git?

Git is a distributed version control system. It allows developers to track changes, create branches and collaborate on projects.

5. Important Git Concepts

  • Repository: Stores project files and their history.
  • Working Directory: Where developers edit files.
  • Staging Area: Holds changes selected for the next commit.
  • Commit: A recorded snapshot of changes.
  • Branch: An independent line of development.
  • Remote: A repository hosted elsewhere, such as GitHub.

6. Clone, Push and Pull

  • git clone copies a remote repository locally.
  • git push uploads local commits to a remote.
  • git pull fetches and integrates remote changes.
