\# DevTrack



DevTrack is a DevOps learning platform designed to help students learn DevOps concepts through lessons, quizzes, and practical challenges.



\## Tech Stack



\- Python

\- Flask

\- SQLite

\- HTML

\- CSS

\- JavaScript

\- Pytest

\- Git

\- GitHub

\- GitHub Actions



\## Project Goals



\- Learn DevOps concepts

\- Practice DevOps through challenges

\- Track learning progress

\- Earn XP and badges

\- Demonstrate CI/CD workflow
